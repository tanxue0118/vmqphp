## 项目简介

V免签（PHP）是基于 ThinkPHP 5.1 + MySQL 实现的一套免签支付程序，主要特色：

- 收款即时到账，无需进入第三方账户，收款更安全
- 提供示例代码，简单接入
- 超简单 Api 使用，提供统一 Api 实现收款回调
- 免费、开源，无后门风险
- 支持监听店员收款信息，可使用支付宝/微信小号、模拟器挂机，方便 iOS 用户
- 免 root、免 Xposed 框架，不修改支付宝/微信客户端，防封更安全

## 原理

用户扫码付款 → 手机通知栏收到收款提醒 → V免签监控端监听到提醒并推送至服务端 → 服务端根据金额匹配是哪笔订单。

## 收支区分说明

- 订单表 `pay_order` 新增 `io` 字段：`1` = 收入，`2` = 支出。
- 监控端推送收款时携带 `io` 参数：支出类收款（如提现、转出）仅记录一条流水，不参与待支付订单匹配、不触发异步通知。
- 订单列表的「收支」列、查询接口 `getOrders` 均支持按 `io` 过滤。

## 环境要求

- PHP >= 5.6
- MySQL
- 推荐使用宝塔面板部署

## 安装

1. 下载源代码（Clone 或 Download ZIP）。
2. 宝塔面板新建网站，设置：
   - 网站目录 → 运行目录设置为 `public` 并保存
   - 伪静态 → 选择 `thinkphp` 并保存
   - 默认文档 → 将 `index.html` 放在第一行并保存
3. 打开 `config/database.php`，设置好 MySQL 账号密码。
4. 导入数据库文件（位于根目录）`vmq.sql` 到数据库。
5. 访问网站后台，默认后台账号和密码均为 `admin`，请登录后自行修改。

## 数据库表

| 表名 | 说明 |
|------|------|
| `pay_order` | 订单表（含 `io` 收支字段） |
| `pay_qrcode` | 收款二维码 |
| `setting` | 系统设置（key-value） |
| `tmp_price` | 金额锁定表（防金额重复匹配） |

## 调用 / Api

部署完成后访问后台「Api 说明」查看详细接口文档，核心接口如下：

| 接口 | 说明 |
|------|------|
| `createOrder` | 创建订单 |
| `getOrder` | 获取订单信息 |
| `checkOrder` | 查询订单状态 |
| `closeOrder` | 关闭订单 |
| `getState` | 获取监控端状态 |
| `appHeart` | 监控端心跳 |
| `appPush` | 监控端收款推送（支持 `io` 收支参数） |

示例代码位于 `public/example/`：`main.php`（下单）、`notify.php`（异步回调）、`return.php`（同步返回）。

## 店员绑定（iOS / 备用机挂机用户）

V免签支持监听「店员」收款通知，可以在安卓备用机或模拟器上挂小号收取收款通知，方便 iOS 用户使用：

- **微信绑定店员**：微信 → 收付款 → 二维码收款 → 收款小账本 → 添加店员接收通知
- **支付宝绑定店员**：我的 → 商家服务 → 店员通 → 立即添加

### 支持的通知类型

- 支付宝个人收款的推送通知
- 支付宝商家二维码的收款推送通知
- 支付宝店员通绑定的店员账号收款的推送通知
- 微信二维码收款推送通知
- 微信店员收款推送通知

## 注意事项

- 本系统原理为监控收款后手机通知栏推送消息，请保持微信 / 支付宝 / V免签监控端后台正常运行，并加入内存清理白名单。
- 监控端不保证适配所有手机，遇到无法正常监听时，请更换手机或使用模拟器挂机。
- 支出记录（`io=2`）仅作流水统计，不参与订单匹配与回调，也不支持补单。
- 请遵守相关法律法规，请勿用于非法用途，商用请申请官方商户接口。
